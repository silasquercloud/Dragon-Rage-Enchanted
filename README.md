## 🌌 Sobre o projeto

O **Dragon Rage Enhanced** é uma versão independente e modificada do projeto Dragon Rage, com melhorias voltadas principalmente para a experiência em dispositivos Android ARM64.

Nosso objetivo é proporcionar uma experiência mais fluida, organizada e personalizável, priorizando a estabilidade dos combates e a compatibilidade com diferentes dispositivos.

O projeto está em desenvolvimento, e algumas funcionalidades ainda são experimentais.

## 🚀 Principais funcionalidades

### ⚡ Desempenho e otimização

- Perfis gráficos: **Desempenho, Equilibrado e Qualidade**.
- Ajuste de resolução interna.
- Otimizações de gerenciamento de recursos gráficos.
- Cache de pipelines Vulkan.
- Diagnósticos e registros de desempenho.
- Melhorias experimentais para GPUs Mali e Adreno.

### 🎮 Controles personalizados

- Controle virtual inspirado no PlayStation 2.
- Ajuste de tamanho e transparência dos botões.
- Reposicionamento dos controles na tela.
- Configurações de visibilidade por botão.
- Salvamento de layouts personalizados.
- Importação e exportação de configurações.
- Suporte a múltiplos toques.

### 🖥️ Interface e gráficos

- Menu de configurações organizado por categorias.
- Modos de adaptação da imagem à tela.
- HUD independente para informações de desempenho.
- Configurações gráficas ajustáveis.
- Recursos experimentais de renderização.

## 📱 Compatibilidade

| Requisito | Descrição |
|---|---|
| Sistema | Android |
| Arquitetura | ARM64 |
| API gráfica | Vulkan |
| GPUs | Mali e Adreno, conforme suporte do dispositivo |
| Estado | Desenvolvimento experimental |

**Observação:** desempenho e compatibilidade variam conforme o processador, a GPU, o driver e a versão do Android.

## 🛠️ Desenvolvimento

O Dragon Rage Enhanced busca aprimorar continuamente:

- Estabilidade dos 30 FPS.
- Redução de travamentos e oscilações de frametime.
- Eficiência da renderização.
- Consumo de memória.
- Compatibilidade gráfica.
- Experiência com controles touchscreen.
- Organização das configurações.

As melhorias são avaliadas progressivamente. Nem todos os recursos experimentais estão disponíveis ou funcionam em todos os aparelhos.

## 📦 Instalação

1. Acesse a seção **Releases** deste repositório, quando houver uma versão publicada.
2. Baixe o APK compatível com Android ARM64.
3. Instale o aplicativo.
4. Forneça seus próprios arquivos de jogo obtidos legalmente, conforme as instruções da versão.
5. Ajuste as configurações gráficas de acordo com seu dispositivo.

**Nenhuma imagem de jogo, BIOS ou outro conteúdo proprietário é distribuído neste repositório.**
